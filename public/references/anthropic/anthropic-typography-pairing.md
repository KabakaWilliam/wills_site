# Anthropic Typography System
## Typography Pairing: Anthropics Sans + Anthropic Serif

### Headings
- **Font**: Anthropics Sans (marker-h): Variable sans-serif
- **Weights**: Medium (500), Semibold (600), Bold (700)
- **Sizes**:
  - Display XL: clamp(2.5rem, 2.04rem + 1.96vw, 4rem)
  - Display XXL: clamp(3rem, 2.39rem + 2.61vw, 5rem)
  - Headline 4: clamp(1.5rem, 2.31rem + 2.82vw, 3.5rem)
  - Headline 6: clamp(1rem, 1.31rem + 0vw, 1.5rem)

### Body Text
- **Font**: Anthropic Serif (serif): Variable serif
- **Sizes**:
  - Body 1: clamp(1.25rem, 1.85rem + 0.65vw, 2.0rem)
  - Body 3: clamp(1rem, 1.34rem + 0.16vw, 1.25rem)
  - Detail XS: clamp(0.75rem, 1.38rem + 0.16vw, 1.5rem)
  - Caption: smaller than body text

### Rhythm
- Tight tracking for headings
- Generous leading for serif body text
- Baseline grid alignment across all fonts
