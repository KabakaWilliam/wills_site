# Anthropic Component Styles

## Buttons
- **Primary**: Black #000000 on ivory #FAF9F5, no border, rounded corners
- **Secondary**: #D6B26C on ivory #FAF9F5
- **Tertiary**: #A45744 on ivory #FAF9F5
- **Icon Right**: Always includes icon button with space before content
- **Paddings**: 
  - Medium: 0.75rem 1.5rem
  - Small: 0.5rem 1rem
- **Variations**: Small/Medium/Large sizes

## Cards & Grids
- **Border Top Flush**: Separators with thin border above content
- **Link Cards**: Hover scale 1.05x transform on image
- **Grid Layout**: 3-4 column responsive grid
- **Meta Sections**: Caption with bold label + time/date
- **Side Lists**: Arrow icon + date + title + body

## Terminal / Code Components
- **Scrollbar**: Custom thin 6px scrollbar (width: 6px, height: 6px)
- **Colors**: rgba(250, 249, 240, 0.3) bar color
- **Space**: 4px-6px margins track to scrollbar

## Visual Elements
- **Logo Marquee**: Infinite loop animation keyframes (fade-in/pause on hover)
- **Data Visualizations**: SVG charts with clean stroke widths (2px)
- **Images**: Lazy loading with blur 'up' from 10px
- **Hero Two Column**: Title subhead + body CTAs layout

## Forms / Inputs
- **Search**: Icon left + input field
- **Badge**: Rounded pill shape, word-limit 5 chars
- **Tab List**: Underline style ASCII theme tabs
